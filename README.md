# Kite — support and privacy

The support page and privacy policy for Kite, the pay-period budgeting app.
Published with GitHub Pages.

- Support: https://shlados.github.io/kite-support/
- Privacy: https://shlados.github.io/kite-support/privacy/

The text of both pages comes from `docs/` in the app repo, which stays the
source of truth; here it has front matter added. The layout, the stylesheet, the
logo and the fonts live in this repo.

The font is Inter, the app's own, served from `assets/fonts/` instead of from
Google, so reading the policy does not send a visitor's address to a third
party. The files are Latin subsets of the 400 and 600 weights, under the SIL Open
Font License (`assets/fonts/OFL.txt`).
